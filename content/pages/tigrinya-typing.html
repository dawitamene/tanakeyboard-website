How it works

Each Ge’ez letter is a consonant plus a vowel. Type the consonant, then the vowel. The tool re-reads the whole word on every keystroke, so a later letter can still change an earlier one: k is ክ, kh is ኽ, and kha is ኻ.

e1st formse → ሰ
u2nd formsu → ሱ

ie5th formsie → ሴ
nothing6th forms → ስ
o7th formso → ሶ

A vowel with no consonant before it writes the ኣ row: a → ኣ, e → እ, i → ኢ, o → ኦ. A comma becomes ፣, a full stop ።, and a question mark ፧.
