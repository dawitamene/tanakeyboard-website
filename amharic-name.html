Spelling a name by sound

  • Each syllable is one letter. ma → ማ, ri → ሪ, ya → ያ.
  • A consonant with no vowel takes the sixth form: n → ን, so bruk → ብሩክ.
  • Capitals give the sharp sounds: T → ጥ, P → ጵ, q → ቅ.
  • ie gives the é sound: mieron → ሜሮን.

The full set of rules is in How to type Amharic with an English keyboard, and every letter is on the Amharic alphabet chart.

Common questions.

How do I write my name in Amharic?

Type it the way it sounds, one syllable at a time: selam → ሰላም. Amharic spells by sound, so Michael is ሚካኤል, not a letter-for-letter copy of the English.

Why does my name look different from the English spelling?

Fidel writes syllables, not single letters, and many names have a traditional Amharic form. John is usually ዮሐንስ and Peter is ጴጥሮስ, from the Ge’ez Bible.

How do I type the ኤ in names like ዳንኤል?

Put an apostrophe before ie when it follows a consonant: dan'iel → ዳንኤል. At the start of a word, ie is enough: ieden → ኤደን.
