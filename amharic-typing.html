How it works

Each Amharic letter is a consonant plus a vowel. Type the consonant, then the vowel, and the matching Fidel appears. The tool re-reads the whole word on every keystroke, so a later letter can still change an earlier one: s is ስ, sh is ሽ, and sha is ሻ.

A vowel with no consonant before it writes the አ row: a → አ, e → እ, i → ኢ. A comma becomes ፣, a full stop ።, and a question mark ፧.

Common questions.

How do I type Amharic online?

Type the Amharic sound with English letters in the left box. The Fidel appears on the right as you type. Press Copy and paste it anywhere: Word, Google Docs, Facebook, Telegram or email.

Why does bet give በት and not ቤት?

In this system e writes the first form (በ) and ie writes the fifth (ቤ). Type biet, or tap ቤት under Other spellings.

How do I write a letter with no vowel, like ስ or ም?

Type the consonant on its own. s gives ስ, so sm gives ስም and yqrta gives ይቅርታ.

How do I type ጠ, ጨ, ጰ and ቀ?

Use capitals for the ejective letters: T for ጠ, C for ጨ, P for ጰ. ቀ is q. The full list is in the Amharic spelling rules.

Is my text saved or sent anywhere?

No. Everything runs in your browser. Your last text is kept only in this browser so it is still there if you reload the page.

Can I type Amharic like this on my phone?

Yes. Addiyon Keyboard uses the same spelling in every Android app, and adds word suggestions from an Amharic dictionary, so bet offers ቤት right away.
