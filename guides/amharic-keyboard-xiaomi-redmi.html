Amharic keyboard on Xiaomi, Redmi and POCO

Xiaomi, Redmi and POCO phones ship with Gboard or their own keyboard, neither of which turns English letters into Fidel. Here is how to add Amharic on HyperOS and MIUI.

Updated October 14, 2026

1. Install and open Addiyon Keyboard

Install Addiyon Keyboard from Google Play and open it. It is free and the dictionary works offline.

2. Turn it on

  1. Tap Enable in settings.
  2. Switch Addiyon Keyboard on. Wait for the short countdown on the notice, then tap OK.

To find the screen yourself, open Settings › Additional settings › Languages & input › Manage keyboards. On some versions it is under Settings › System. Searching Settings for keyboard also works.

3. Switch to it

Back in Addiyon, tap Switch keyboard and pick Addiyon Keyboard. You can also set it in Languages & input › Current keyboard.

4. Stop it switching back

HyperOS and MIUI are strict about background apps. If your keyboard changes back after a restart:

  • Open Settings › Apps › Manage apps › Addiyon Keyboard.
  • Set Battery saver to No restrictions.
  • Turn on Autostart.
  • Choose Addiyon again as the current keyboard.

5. Type Amharic

Type the sound in English letters: selam → ሰላም, amargna → አማርኛ. Tap the globe key for English. The spelling rules explain the letters that need Shift.

Common questions.

Where is the keyboard setting on Xiaomi and Redmi?

Usually Settings › Additional settings › Languages & input › Manage keyboards. The fastest way is to open Addiyon and tap Enable in settings, which opens the right screen directly.

Why does my Redmi switch back to Gboard?

HyperOS and MIUI can stop apps in the background to save battery. Set Addiyon’s battery saver to No restrictions and turn on Autostart for it, then choose Addiyon again as your keyboard.

Does it work on older MIUI versions?

Yes. The menu names differ a little between MIUI and HyperOS, but the steps are the same. Searching Settings for keyboard finds the right screen on every version.
