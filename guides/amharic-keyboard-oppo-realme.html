Amharic keyboard on Oppo, realme and OnePlus

Oppo, realme and OnePlus phones come with keyboards that do not type Amharic. Here is how to add one on ColorOS, realme UI and OxygenOS.

Updated October 14, 2026

1. Install and open Addiyon Keyboard

Install Addiyon Keyboard from Google Play and open it.

2. Turn it on

  1. Tap Enable in settings.
  2. Switch Addiyon Keyboard on and confirm the notice.

To find the screen yourself, open Settings › Additional settings › Keyboard & input method, or search Settings for keyboard.

3. Make it the default

Back in Addiyon, tap Switch keyboard and pick Addiyon Keyboard. On the Keyboard & input method screen you can also set it as the Current keyboard.

4. Keep it working

  • Open Settings › Apps › App management › Addiyon Keyboard › Battery and allow background activity.
  • If your phone has Auto launch, turn it on for Addiyon.

5. Type Amharic

Type the sound in English letters: selam → ሰላም. Tap the globe key for English, and see the spelling rules for letters like ጠ and ጸ.

Common questions.

Where is the keyboard setting on Oppo and realme?

Usually Settings › Additional settings › Keyboard & input method. The fastest way is to open Addiyon and tap Enable in settings, which opens the right screen directly.

My keyboard switches back to the old one. What do I do?

Allow Addiyon to run in the background: open its app info, go to Battery, and allow background activity. Then choose Addiyon again as the default keyboard.

Is it the same on OnePlus?

Yes. OnePlus now uses the same system as Oppo, so the menus match. Searching Settings for keyboard finds the screen on any version.
