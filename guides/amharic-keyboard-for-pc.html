Amharic keyboard for PC

There are three good free ways to type Amharic on a Windows or Mac computer. Pick by how often you type.

Updated October 13, 2026

1. Online, with nothing to install

The online Amharic typing tool works in any browser. Type selam, see ሰላም, press Copy Amharic and paste it into Word, Gmail, Facebook or Telegram. It is the quickest choice on a shared or office computer, and nothing you type leaves the browser.

2. Windows’ own Amharic input method

Windows 10 and 11 include an Amharic input method.

  1. Open Settings › Time & language › Language & region.
  2. Choose Add a language, search for Amharic and install it.
  3. Switch between languages with Windows + Space.

Its spelling differs in places from the system on this site, so check its help if a letter will not come out.

3. Keyman, for Windows, Mac and Linux

Keyman is free and open source. Its GFF Amharic keyboard, by the Ge’ez Frontier Foundation, uses phonetic typing similar to SERA and works on Windows, macOS and Linux. It is a good choice if you type Amharic every day on a computer.

On your phone

On Android, Addiyon Keyboard uses the same spellings as the online tool and adds an Amharic dictionary, so whole words appear as you type. See How to type Amharic on Android.

Common questions.

Is there an Addiyon Keyboard for PC?

Not yet. Addiyon Keyboard is an Android app. On a computer, the online typing tool uses the same spellings.

What is the best free Amharic keyboard for Windows?

For occasional typing, the online tool needs nothing installed. For daily typing in Word and other programs, add Windows’ own Amharic input method or install Keyman with the GFF Amharic keyboard.

How do I type Amharic in Microsoft Word?

Use an Amharic input method on your computer and type straight into Word, or write in the online tool and paste. Word displays Amharic with the Ethiopic fonts Windows includes, such as Nyala and Ebrima.

Is Power Geez still needed?

No. Older guides recommend Power Geez, but Unicode keyboards like the ones on this page work with every modern program and website, and the text stays readable on any phone.
