Amharic keyboard on Tecno, Infinix and itel

Tecno, Infinix and itel phones are everywhere in Ethiopia, but their built-in keyboards rarely include Amharic. Here is how to add one on HiOS, XOS and itel OS.

Updated October 13, 2026

1. Install and open Addiyon Keyboard

Install Addiyon Keyboard from Google Play and open it. It is free and works offline, so typing never uses your data bundle.

2. Turn it on

  1. Tap Enable in settings.
  2. Switch Addiyon Keyboard on and tap OK on the notice.

If you need to find the screen yourself, it is usually Settings › System › Languages & input › On-screen keyboard. Some versions call it Virtual keyboard or Manage keyboards. Searching Settings for keyboard also works.

3. Switch to it

Back in Addiyon, tap Switch keyboard and pick Addiyon Keyboard. If the switcher does not open, tap any text box, pull down the notification shade and tap Change keyboard or Choose input method.

4. Keep it working

These phones come with strong battery and memory savers. If the keyboard disappears after a restart or falls back to the old one:

  • Open Settings › Apps › Addiyon Keyboard › Battery and allow it to run without restrictions.
  • In the phone manager or App launch setting, allow Addiyon to start automatically.
  • Make Addiyon the default again from the keyboard switcher.

5. Type Amharic

Type the sound in English letters: selam → ሰላም, yqrta → ይቅርታ. Tap the globe key for English. For the letters that need Shift, see the spelling rules.

Common questions.

Where is the keyboard setting on Tecno and Infinix?

Usually Settings › System › Languages & input › On-screen keyboard (sometimes called Virtual keyboard or Manage keyboards). The fastest way is to open Addiyon and tap Enable in settings, which opens the right screen directly.

My phone keeps switching back to the old keyboard. What do I do?

Make Addiyon the default from the keyboard switcher, then check the phone’s battery or app-launch manager and let Addiyon run normally. Aggressive battery savers can stop a keyboard in the background.

Does it work on cheap phones with little storage?

Yes. Addiyon is built to stay quick on budget phones, and the dictionary works offline, so it does not use mobile data while you type.
