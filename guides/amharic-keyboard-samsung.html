How to add an Amharic keyboard on Samsung

Samsung Keyboard has no Amharic option, so on a Galaxy phone you add a separate Amharic keyboard. This takes about two minutes, and Samsung Keyboard stays installed for when you want it.

Updated October 13, 2026

1. Install Addiyon Keyboard

Get Addiyon Keyboard from Google Play (not the Galaxy Store). It is free and has no ads.

2. Turn it on

  1. Open Addiyon and tap Enable in settings.
  2. Switch Addiyon Keyboard on in the list, then tap OK on Android’s notice.

To reach the screen yourself: Settings › General management › Keyboard list and default.

3. Make it the default

  1. Back in Addiyon, tap Switch keyboard and choose Addiyon Keyboard.
  2. Or, in Keyboard list and default, tap Default keyboard and pick Addiyon.

Turning on Keyboard button on navigation bar on the same Samsung screen adds a small keyboard icon at the bottom of the screen, so you can jump between Addiyon and Samsung Keyboard in any app.

4. Start typing

Type Amharic sounds with English letters: selam → ሰላም, endiet neh → እንዴት ነህ. Tap the globe key for English. The spelling rules cover the letters that need Shift.

Samsung-specific tips

  • Keyboard looks too small or too tall? Change the height in Addiyon’s settings rather than Samsung’s; Samsung’s size setting applies only to Samsung Keyboard.
  • Dark mode: Addiyon follows the phone’s light or dark setting automatically.

Common questions.

Does Samsung Keyboard support Amharic?

No. Samsung Keyboard does not offer Amharic as a language, so Galaxy owners install a separate keyboard app for it.

Will I lose Samsung Keyboard?

No. It stays on your phone. You can switch back any time from Keyboard list and default or the keyboard switcher.

Where is the keyboard setting on Samsung?

Open Settings › General management › Keyboard list and default. On older One UI versions it is under General management › Language and input › On-screen keyboard.

Does it work on Galaxy A, M and S phones?

Yes. Addiyon Keyboard runs on any Samsung Galaxy phone with a supported Android version on Google Play, including the A, M, F, S and Z series.
